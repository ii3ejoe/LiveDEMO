Frequently asked questions

Tap a question to expand. Tap again (or the arrow) to collapse.

Is Iowa Neighbor free to use?

Yes. The directory is free. Donations are voluntary and never required to search or save resources for offline use.

Does it work without internet?

Yes, for the core experience. Use Online → save a copy for offline viewing. Later, with no connection, you can still open the app shell and any list you saved. Online features (fresh updates, geocoding, some maps) need a connection.

Why do I see no results until I search?

The list stays empty until you click Search. That keeps the first screen clear and makes online vs offline behavior easier to understand in demos and daily use.

Are the resources always 100% up to date?

We aim for reliable, verified information, but hours and eligibility change. Always confirm with the organization before referring someone or traveling for help. Look for last-updated notes when shown.

What does “User submitted” mean?

That resource came from a community or partner submission (or an imported list) and was reviewed for the public list. Treat it like any other entry: verify details with the organization.

How do I suggest a new resource or a correction?

Use Share a Resource to suggest something new (reviewed before it goes public). Use Feedback for questions or corrections.

Can I install this on my phone or computer?

Yes. Use Add a Shortcut / Add to Home Screen when your browser offers it. That installs a shortcut icon without an app store. You still use the same site—online when available, offline for what you saved.

What does clearing cache do?

A normal browser “clear cache” may refresh site files but should not remove your offline resource save. To remove saved offline data, use the site’s Remove offline copy control (or clear site data for this site only, which is intentional and stronger).

Is this an official government or 211 site?

No. Iowa Neighbor is an independent project (Out of Memory Solutions / iD10T). Sample or public data may be used for demos; always verify before relying on a listing.

How can I support the project?

Use and share it. If you want to help with costs (hosting, tools), visit the Support page. Donations don’t unlock features—they help keep access available.

I saved for offline, but it doesn’t show later — did clear cache delete it?

Usually no. A normal “clear cache” or “cached images and files” does not remove your offline resource copy.

Your offline list is stored separately on the device (site storage). It is removed when you:

  • Tap Remove offline copy in the Online/Offline popup, or
  • Use Clear site data / “Cookies and site data” for this site only, or
  • Clear all browser data / reset the app in a way that wipes site storage.

If offline seems empty: go online, open the site, use Save for offline viewing, and confirm it says Saved · N resources (N greater than 0). Then try offline again and click Search.

How do I uninstall Iowa Neighbor (desktop & mobile)?

If you used Add a Shortcut / Add to Home Screen, you can remove it like any other installed site or app:

Windows (Chrome / Edge)

  • Open the installed app → menu (⋮) → Uninstall Iowa Neighbor, or
  • Settings → Apps → Installed apps → find Iowa Neighbor → Uninstall, or
  • Right-click the taskbar/start icon → Uninstall.

macOS (Chrome / Edge)

  • Open the app → menu → Uninstall, or
  • In Chrome: chrome://apps → right-click Iowa Neighbor → Remove.

Linux (Chrome / Chromium)

  • chrome://apps → right-click → Remove, or remove the .desktop shortcut from your app menu.

Android

  • Long-press the home screen icon → Uninstall / App info → Uninstall, or
  • Settings → Apps → Iowa Neighbor → Uninstall.

iPhone / iPad (Safari)

  • Long-press the home screen icon → Remove App → Delete App (this removes the home screen shortcut).

Uninstalling the shortcut does not always erase offline data immediately; use Remove offline copy in the site, or clear site data for this site, if you want the saved list gone too.
